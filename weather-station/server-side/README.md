Server Side
---

**GR** Αυτός είναι ο υποφάκελος που περιέχει ότι έχει να κάνει σχέση με τον **διακομιστή** του μετεωρολογικού σταθμού. Εφόσον σκεφτόμαστε την ενεργειακή απόδοση και δεν θέλουμε να φτάνουμε στα άκρα το ενεργειακό απόθεμα του σταθμού ώστε να αυξηθεί η ενεργή του δράση, ο διακομιστής λαμβάνει τα πακεταρισμένα δεδομένα, τα επεξεργάζεται με κατάλληλο τρόπο και τα παρουσιάζει σε μια OLED οθόνη (στην πρώτη έκδοση που αποδεικνύουμε την λειτουργικότητα της ιδέας)

**EN** This is the sub-directory that includes everything related to the **server** of the weather station. Since we are thinking about the energy expenditure and we do not want to deplete the station's weather budget to extend its active time, the server will receive the packaged data, process it in a proper manner and display it on an OLED screen (in the first version which is Proof of Concept)
