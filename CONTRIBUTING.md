Contributions
---

This repository hosts the Hardware Systems Branch's OpenSky project. We will not modify the team's efforts with files that are not from the project team. We will gladly host /community-mods, releases and
it is recommended that you fork the repository and modify our design to your heart's desire.


For the members of the student team 2 rules apply:
1. Never commit to main immediately, create a new branch and consult other team members and core contributors
2. Usage of AI for writing code and schematics is not something we want, we want to develop skills, not vibecode
